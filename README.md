## 🧠 Knowledge Base (Notion)

My primary learning system lives in *Notion* and acts as a structured database for working with LeetCode:

- spaced repetition schedule  
- first solve and review dates  
- confidence tracking  
- step-by-step explanations of solutions (in Russian)  
- final, cleaned-up reference implementations  

### How this repository fits into the process

I solve LeetCode problems **primarily in Jupyter notebooks**.

This allows me to:
- iterate freely,
- experiment with ideas,
- make mistakes,
- and gradually arrive at a working solution.

The notebooks in this repository mostly reflect this **raw problem-solving process** — the path toward the solution rather than a polished final result.

Once a solution is clear, I:
- extract the core idea,
- rewrite the solution in a clean reference form,
- and document the reasoning step by step in my Notion database.

As a result:
- **GitHub** stores the raw LeetCode work and learning traces  
- **Notion** stores the structured knowledge: explanations, reviews, and final solutions  

Regular commits here reflect consistent practice over time, while the Notion dashboard below shows how the learning process itself is organized.
